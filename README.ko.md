# Retext PDF

> 옛 이름은 EDITOR_KIM입니다(v4.0.0에서 이름을 바꿨습니다). 저장소도 `kindsusu/retext-pdf`로 옮겼고 옛 주소는 GitHub이 새 주소로 연결합니다.

![Retext PDF](assets/hero.png)

PDF의 텍스트를 직접 고치고, 민감한 글자를 실제로 제거하는 Windows용 로컬 편집기입니다. Markdown 편집도 함께 됩니다. 모든 처리는 PC 안에서 이뤄지며 문서는 PC 밖으로 나가지 않습니다.

[English](README.md) · [계획](PLAN.md) · [릴리스](https://github.com/kindsusu/retext-pdf/releases)

## 다운로드

**[Releases](https://github.com/kindsusu/retext-pdf/releases/latest)**에서 최신 빌드를 받습니다.

| 파일 | 이럴 때 |
|---|---|
| `Retext-PDF-<버전>-setup.exe` | 일반 설치(사용자별, 관리자 권한 불필요). PDF "연결 프로그램" 목록과 시작 메뉴에 등록됩니다. |
| `Retext-PDF-<버전>-portable.exe` | 설치 없이 폴더나 USB에서 바로 실행합니다. |

요구 사항: Windows 10·11(x64), 디스크 약 400MB. 계정이나 인터넷 연결이 필요 없습니다.

**처음 실행할 때 SmartScreen.** 아직 코드 서명이 없어 "Windows의 PC 보호" 창이 뜰 수 있습니다. 이 저장소의 Releases에서 받은 파일인지 확인한 뒤 **추가 정보 → 실행**을 누르세요. 또는 받은 파일을 우클릭 → **속성** → **차단 해제**에 체크 → 확인을 누르면 경고 없이 열립니다. 경고를 피하려고 Microsoft Defender를 끄지 마세요.

## 3.0에서 달라진 점

- 굵게·그림자 효과로 같은 글자를 두 번 겹쳐 그린 PDF에서, 가린 글자가 저장 후 다시 나타나던 문제를 막았습니다.
- 한 줄을 고칠 때 파일이 커지지 않습니다(1.4MB 문서가 27MB가 되던 경우). 수백 MB PDF에서도 메모리가 부족해 멈추지 않습니다.
- 수정이 실패하면 입력한 글이 남고 문서와 실행 취소 기록은 그대로입니다. 다른 프로그램이 파일을 바꿔도 저장하지 않은 편집을 버리지 않습니다.
- 전자계약서의 입력 칸(숫자·주소)을 한 글자씩이 아니라 한 상자로 고칩니다.
- 큰 한글 Markdown 문서가 글자 깨짐 없이 저장되고, Markdown 링크는 앱 창이 아니라 브라우저로 열립니다.

전체 내용: [v3.0.0 릴리스](https://github.com/kindsusu/retext-pdf/releases/tag/v3.0.0)

## 주요 기능

- 원본 임베드 폰트를 유지한 채 PDF 텍스트 객체를 직접 편집 (없는 글리프는 맑은 고딕 서브셋으로 대체)
- 선택한 문자를 PDF에서 제거한 뒤 재추출로 확인하는 가리기(마스킹); 검색 결과를 우클릭해 "줄 전체 가리기"도 가능
- 문서 전체 텍스트 검색(Ctrl+F) — 이전/다음 이동, 건수 표시, 대소문자 구분, 강조 표시
- 페이지 도구: 페이지 정리(추출/삭제), 쪽 단위·축소본 회전, 축소본 드래그로 순서 변경, N쪽씩 분할, 병합, PNG/JPEG로 내보내기, 이미지 삽입, 다운샘플링으로 용량 줄이기(파일 여러 개를 열지 않고 한 번에 줄이는 것도 가능)
- 상태줄(현재쪽/전체쪽, 쪽 번호 입력, 확대 슬라이더)과 사이드바 파일/페이지 탭(열어 둔 파일, 쪽 축소본)
- 문서가 없을 때 빠른 도구(병합·여러 파일 용량 줄이기·이미지로 내보내기)가 있는 빈 상태와 전체 창 드래그 앤 드롭 오버레이
- Windows "연결 프로그램" 등록으로 브라우저·메일에서 PDF 바로 열기 (임시 파일은 배너와 "다른 이름으로 저장" 안내)
- 실행 취소/다시 실행, 여러 줄 편집, 폭 맞춤, 이동 — 정렬을 유지한 편집도 Ctrl+Z 한 번에 되돌아갑니다
- 안전한 편집: 줄을 고치면 적용 → 저장 → 다시 열기 → 확인을 거친 뒤에만 반영하고, 실패하면 원래대로 되돌립니다
- 오래 걸리는 문서 도구(용량 줄이기·내보내기·분할·병합·페이지 정리)는 진행 창과 [취소] 버튼을 제공하며, 취소하면 문서를 원래 상태로 되돌리거나 그때까지 저장된 파일 수를 알려줍니다
- 페이지 삭제·용량 줄이기·회전·순서 변경 뒤에는 상태줄 알림과 별개로 실행 취소 토스트가 뜹니다
- Markdown 편집과 안전한 실시간 미리보기

## 소스에서 실행

```bash
git clone https://github.com/kindsusu/retext-pdf.git
cd retext-pdf
npm install
npm start
```

터미널 없이 같은 소스를 실행하려면 `run-retext-pdf.bat`을 더블클릭합니다. 브라우저 전용 모드는 `npm run serve` 후 <http://localhost:4747>에서 열리며, 이 모드에서는 파일 대화상자와 PNG 삽입을 쓸 수 없습니다(Electron 전용).

## PDF 편집

![구조](assets/architecture.svg)

한 줄을 클릭해 내용을 바꾸고 Enter로 확정합니다. 엑셀·한글·Chromium이 내보낸 PDF는 한 줄을 글꼴 경계나 글자마다 쪼개 저장하는데, 기준선이 같고 붙어 있는 조각을 한 상자로 묶어 줄 단위로 고칠 수 있게 합니다(표의 옆 칸은 간격과 세로 괘선으로 구분해 묶지 않습니다). 가능한 한 원본 임베드 폰트를 유지하며, 원본에 없는 글자는 맑은 고딕으로 대체됩니다. 이미지 위의 투명 검색 글자이거나 이미 폰트를 지정한 텍스트 상자는 **폰트 맞추기** 창이 열립니다 — 설치된 폰트를 고르거나 TTF를 가져와 미리보기 후 적용하며, 실행 취소를 지원합니다. 그림으로 그려진 글자처럼 원래 글꼴을 다시 쓸 수 없으면 창이 그렇게 알려 주고, 비슷한 글꼴을 직접 골라 미리 보며 맞춥니다. 일반 TTF만 지원하며 OTF나 가변 폰트는 지원하지 않습니다.

![가리기 절차](assets/redaction.svg)

텍스트 가리기는 선택한 문자를 PDF 객체에서 제거하고 가리는 사각형을 추가한 뒤, 페이지 텍스트를 재추출해 제거를 확인합니다. 스캔 이미지 안의 글자는 시각적으로 덮을 수만 있고 제거되지는 않습니다.

## 개인정보와 안전

- 문서는 PC 밖으로 나가지 않습니다. 계정·클라우드·AI 연동이 없고, 내장 서버는 `127.0.0.1`에서만 동작하며 다른 사이트에서 온 요청은 거부합니다(Host·Origin 검사).
- Markdown 안의 링크는 기본 브라우저로 열고, 원격 이미지는 자동으로 불러오지 않습니다.
- 가리기는 글자를 파일에서 실제로 지운 뒤 페이지 텍스트를 다시 추출해 확인합니다. 스캔 이미지는 덮기만 할 수 있습니다.

## PDF 도구

도구줄의 **페이지**·**문서** 묶음은 아래 문서 단위 도구를 제공합니다(이미지로 내보내기·분할은 새 파일을 만들 뿐 열린 문서는 그대로라 실행 취소 대상이 아니고, 나머지는 모두 실행 취소 가능).

- **페이지 정리…** — 축소본 체크박스 또는 `1,3-5` 범위로 페이지를 추출/삭제
- **↺ / ↻** — 현재 쪽을 90도 회전. 사이드바 축소본 우클릭 메뉴에서도 그 쪽만 회전하거나 "새 파일로 저장…"(그 쪽 하나만 새 PDF로) 할 수 있습니다
- 사이드바 **페이지** 탭에서 축소본을 드래그하면 페이지 순서가 바뀝니다
- **분할…** — N쪽씩 잘라 고른 폴더에 새 PDF 여러 개로 저장
- **병합…** — 여러 PDF를 원하는 순서로 병합
- **이미지로 내보내기…** — 페이지를 96~300dpi PNG/JPEG로 폴더에 저장
- **이미지 삽입** — JPEG/PNG를 삽입, 드래그로 이동, 손잡이로 크기 조절
- **용량 줄이기…** — 기준 dpi 이상 이미지를 다운샘플링하고 JPEG로 재압축, 목표 용량 지정 가능(투명 이미지는 건너뜀). 빈 상태의 **여러 파일 용량 줄이기…** 로 문서를 열지 않고도 PDF 여러 개를 한 번에 줄여 원본 옆에 "…-축소.pdf"로 저장할 수 있습니다

회전한 쪽에서도 글줄·가림 상자·검색 강조·드래그 이동이 화면과 어긋나지 않습니다 — 화면 표시는 PDF의 회전 전 좌표계와 회전 후 화면 배치를 서로 변환해 맞춥니다.

## 자주 묻는 질문

**SmartScreen 경고를 없앨 수 있나요?** 코드 서명을 해야 없어집니다. 검토 중인 방법은 [계획](PLAN.md)에 있습니다. 그전까지는 위의 "추가 정보 → 실행" 또는 "차단 해제"를 쓰세요.

**고친 글자가 맑은 고딕으로 바뀌었어요.** PDF에는 보통 이미 쓰인 글자 모양만 들어 있습니다. 원래 글꼴에 없는 새 글자는 맑은 고딕으로 그립니다. **폰트 맞추기**로 더 비슷한 설치 글꼴이나 TTF를 지정할 수 있습니다.

**수정이 이유와 함께 거부됐어요.** 어떤 글꼴로도 그릴 수 없는 수식 기호·이모지가 든 줄, 그리고 입력한 글자와 다른 글자가 저장되는 일부 PDF 글꼴은 틀린 글을 저장하지 않도록 수정을 막습니다.

**암호가 걸린 PDF**는 열 수 없습니다. 암호를 건 프로그램에서 암호를 푼 뒤 다시 여세요.
