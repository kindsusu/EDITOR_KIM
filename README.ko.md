# EDITOR_KIM

![EDITOR_KIM](assets/hero.png)

PDF의 텍스트를 직접 고치고, 민감한 글자를 실제로 제거하는 Windows용 로컬 편집기입니다. Markdown 편집과 Claude Code·ChatGPT(Codex) 기반 AI 도우미도 선택적으로 쓸 수 있으며, API 키는 필요 없습니다.

[English](README.md) · [계획](PLAN.md)

## 주요 기능

- 원본 임베드 폰트를 유지한 채 PDF 텍스트 객체를 직접 편집 (없는 글리프는 맑은 고딕 서브셋으로 대체)
- 선택한 문자를 PDF에서 제거한 뒤 재추출로 확인하는 가리기(마스킹); 검색 결과를 우클릭해 "줄 전체 가리기"도 가능
- 문서 전체 텍스트 검색(Ctrl+F) — 이전/다음 이동, 건수 표시, 대소문자 구분, 강조 표시
- 페이지 도구: 페이지 정리(추출/삭제), 쪽 단위·축소본 회전, 축소본 드래그로 순서 변경, N쪽씩 분할, 병합, PNG/JPEG로 내보내기, 이미지 삽입, 다운샘플링으로 용량 줄이기(파일 여러 개를 열지 않고 한 번에 줄이는 것도 가능)
- 상태줄(현재쪽/전체쪽, 쪽 번호 입력, 확대 슬라이더)과 사이드바 파일/페이지 탭(열어 둔 파일, 쪽 축소본)
- 문서가 없을 때 빠른 도구(병합·여러 파일 용량 줄이기·이미지로 내보내기)가 있는 빈 상태와 전체 창 드래그 앤 드롭 오버레이
- Windows "연결 프로그램" 등록으로 브라우저·메일에서 PDF 바로 열기 (임시 파일은 배너와 "다른 이름으로 저장" 안내)
- 실행 취소/다시 실행, 여러 줄 편집, 폭 맞춤, 이동
- Markdown 편집과 안전한 실시간 미리보기
- AI 도우미(Claude Code 또는 ChatGPT/Codex), 문서별 대화와 폰트 추천 — 로그인은 AI 기능을 처음 쓸 때만 요청

## 빠른 시작

Releases에서 portable 또는 setup 실행 파일을 받습니다. setup 빌드는 EDITOR_KIM을 Windows PDF "연결 프로그램" 목록에 등록합니다(기본 뷰어로 지정하지는 않습니다). 서명되지 않은 빌드는 SmartScreen이 뜰 수 있으니 출처를 확인한 뒤 "추가 정보 → 실행"을 선택하세요. 차단을 피하려고 Windows Defender를 끄지 마세요. 개발 실행:

```bash
git clone https://github.com/kindsusu/EDITOR_KIM.git
cd EDITOR_KIM
npm install
npm start
```

터미널 없이 같은 소스를 실행하려면 `run-editor-kim.bat`을 더블클릭합니다. 브라우저 전용 모드는 `npm run serve` 후 <http://localhost:4747>에서 열리며, 이 모드에서는 파일 대화상자와 PNG 삽입을 쓸 수 없습니다(Electron 전용).

## AI 로그인

실행할 때는 아무것도 요청하지 않으며, PDF·Markdown 편집은 계정 없이 됩니다. 채팅 패널을 열거나 **보내기**를 누르거나 폰트 추천을 요청하는 첫 순간, EDITOR_KIM이 **Claude**(Claude Code) 또는 **ChatGPT**(Codex) 중 하나를 고르는 창을 띄우고 해당 서비스만 설치·로그인을 안내합니다. 설치는 WinGet의 공식 패키지(`Anthropic.ClaudeCode` 또는 `OpenAI.Codex`)를 사용하고, 로그인은 사용자가 이미 보유한 구독 계정으로 각 서비스의 브라우저 인증을 거칩니다. EDITOR_KIM 자체는 API 키나 토큰을 저장하지 않습니다. AI 기능을 사용하면 현재 문서의 텍스트(폰트 추천의 경우 선택 영역의 이미지)가 선택한 공급자로 전송됩니다.

## PDF 편집

![구조](assets/architecture.svg)

텍스트 상자를 클릭해 내용을 바꾸고 Enter로 확정합니다. 가능한 한 원본 임베드 폰트를 유지하며, 원본에 없는 글자는 맑은 고딕으로 대체됩니다. 이미지 위의 투명 검색 글자이거나 이미 폰트를 지정한 텍스트 상자는 **폰트 맞추기** 창이 열립니다 — 설치된 폰트를 고르거나 TTF를 가져와 미리보기 후 적용하며, 실행 취소를 지원합니다. AI 폰트 추천은 창 안의 버튼을 눌렀을 때만 실행되고, 일반 TTF만 지원하며 OTF나 가변 폰트는 지원하지 않습니다.

![가리기 절차](assets/redaction.svg)

텍스트 가리기는 선택한 문자를 PDF 객체에서 제거하고 가리는 사각형을 추가한 뒤, 페이지 텍스트를 재추출해 제거를 확인합니다. 스캔 이미지 안의 글자는 시각적으로 덮을 수만 있고 제거되지는 않습니다.

## PDF 도구

도구줄의 **페이지**·**문서** 묶음은 아래 문서 단위 도구를 제공합니다(이미지로 내보내기·분할은 새 파일을 만들 뿐 열린 문서는 그대로라 실행 취소 대상이 아니고, 나머지는 모두 실행 취소 가능).

- **페이지 정리…** — 축소본 체크박스 또는 `1,3-5` 범위로 페이지를 추출/삭제
- **↺ / ↻** — 현재 쪽을 90도 회전. 사이드바 축소본 우클릭 메뉴에서도 그 쪽만 회전하거나 "새 파일로 저장…"(그 쪽 하나만 새 PDF로) 할 수 있습니다
- 사이드바 **페이지** 탭에서 축소본을 드래그하면 페이지 순서가 바뀝니다
- **분할…** — N쪽씩 잘라 고른 폴더에 새 PDF 여러 개로 저장
- **병합…** — 여러 PDF를 원하는 순서로 병합
- **이미지로 내보내기…** — 페이지를 96~300dpi PNG/JPEG로 폴더에 저장
- **이미지 삽입** — JPEG/PNG를 삽입, 드래그로 이동, 손잡이로 크기 조절
- **용량 줄이기…** — 기준 dpi 이상 이미지를 다운샘플링하고 JPEG로 재압축, 목표 용량 지정 가능(투명 이미지는 건너뜀). 빈 상태의 **여러 파일 용량 줄이기…** 로 문서를 열지 않고도 PDF 여러 개를 한 번에 줄여 원본 옆에 "…-축소.pdf"로 저장할 수 있습니다

회전한 쪽에서도 글줄·가림 상자·검색 강조·드래그 이동이 화면과 어긋나지 않습니다 — 화면 표시는 PDF의 회전 전 좌표계와 회전 후 화면 배치를 서로 변환해 맞춥니다.

## 단축키

| 키 | 기능 |
|---|---|
| `Ctrl+S` | 저장 |
| `Ctrl+Shift+S` | 다른 이름으로 저장 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Ctrl+J` | AI 패널 접기 / 펼치기 |
| `Ctrl+F` | 검색 막대 열기 |
| `Enter` / `Shift+Enter` (검색창에서) | 다음 / 이전 결과 |
| `Esc` (검색창에서) | 검색 막대 닫기 |
| `PageUp` / `PageDown` / `Home` / `End` | 한 쪽 이동 / 처음 쪽 / 마지막 쪽 |
| `Ctrl` + 마우스 휠 | 커서 위치 기준 PDF 확대 / 축소 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 확대 / 축소 / 페이지 폭 맞춤 |
| `Enter` / `Shift+Enter` | AI 질문 보내기 / 입력창 줄바꿈 |
| `Esc` (입력창에서) | 생성 중인 AI 응답 중지 |
| `F12` | 개발자 도구 |

## 한계

- Windows 10 이상을 주 대상으로 하며 Windows 11에서 검증했습니다.
- 스캔 이미지 안의 글자는 직접 편집하지 않습니다.
- 복잡한 CJK 합자·세로쓰기·특수 폰트는 폴백이 필요할 수 있습니다.
- PDF 전체를 외부 서비스로 업로드하지 않지만, AI에 보낸 문서 텍스트는 선택한 공급자로 전송됩니다.
- 상업·업무용 사용은 라이선스를 확인해야 합니다.
